# Roles y responsabilidades del equipo

## Proyecto

**GuardIA: Sistema de videovigilancia inteligente con detección de eventos mediante inteligencia artificial**

## Objetivo

Documentar los roles y responsabilidades de los integrantes del equipo de trabajo para organizar mejor las actividades del proyecto, evitar duplicidad de tareas y asegurar que cada integrante conozca sus funciones dentro del desarrollo.

## Roles del equipo

| Rol | Responsabilidades |
|---|---|
| Líder de proyecto | Organizar actividades, revisar avances, coordinar reuniones y verificar el cumplimiento de entregas |
| Encargado de documentación | Elaborar y actualizar documentos técnicos, manuales, evidencias y archivos del repositorio |
| Desarrollador backend | Crear la lógica del servidor, endpoints, conexión con base de datos y servicios web |
| Desarrollador frontend | Diseñar y desarrollar la interfaz del sistema para los usuarios |
| Encargado de base de datos | Diseñar tablas, relaciones, consultas y almacenamiento de información del sistema |
| Encargado de inteligencia artificial | Apoyar en el desarrollo o integración del módulo de análisis de imágenes o video |
| Encargado de pruebas | Revisar que el sistema funcione correctamente y reportar errores encontrados |
| Encargado de repositorio | Mantener organizado el repositorio, revisar commits, ramas, carpetas y archivos |

## Responsabilidades generales

Todos los integrantes del equipo deberán cumplir con las siguientes responsabilidades:

1. Participar activamente en el desarrollo del proyecto.
2. Cumplir con las tareas asignadas en tiempo y forma.
3. Mantener comunicación constante con el equipo.
4. Documentar los cambios importantes realizados.
5. Subir avances al repositorio de GitHub.
6. Revisar que los archivos estén correctamente nombrados.
7. Apoyar en la solución de errores o problemas.
8. Respetar las normas de trabajo colaborativo.

## Asignación de actividades

| Actividad | Responsable |
|---|---|
| Crear estructura del repositorio | Equipo de desarrollo |
| Elaborar manual de instalación | Encargado de documentación |
| Crear diagrama de flujo del sistema | Encargado de documentación y desarrollo |
| Documentar roles del equipo | Encargado de documentación |
| Crear normas colaborativas | Equipo completo |
| Desarrollar conexión con API | Desarrollador backend |
| Organizar evidencias | Encargado de repositorio |
| Revisar avances finales | Líder de proyecto |

## Importancia de definir roles

La definición de roles permite que el equipo trabaje de forma más ordenada. Además, ayuda a identificar quién es responsable de cada parte del proyecto y facilita la revisión de avances durante el desarrollo.

## Conclusión

La documentación de roles y responsabilidades dentro del proyecto GuardIA permite mantener una mejor organización del equipo. Cada integrante puede identificar sus tareas, apoyar en las áreas necesarias y contribuir al cumplimiento de los objetivos del proyecto.
